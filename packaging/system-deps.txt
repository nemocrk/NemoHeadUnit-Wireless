# packaging/system-deps.txt
#
# APT system dependencies for NemoHeadUnit-Wireless.
#
# Format: one package per line.
# Lines starting with # are comments.
# Blank lines are ignored.
#
# This file is read by packaging/build_deb.sh to:
#   1. Declare --depends entries in the .deb (runtime deps, auto-installed
#      by apt when the user runs: sudo apt install ./nemo-headunit_*.deb)
#   2. Install them locally before building, to satisfy FPM's dependency
#      resolution and Conda env creation.
#
# Rules:
#   - List ONLY packages needed at RUNTIME on the target machine.
#   - Do NOT list build-only tools (fpm, conda, curl…) — those belong in
#     the CI/dev machine setup, not in the .deb.
#   - Minimum version constraints are expressed as: pkg (>= version)
#     FPM passes these verbatim to dpkg's Depends: field.
#
